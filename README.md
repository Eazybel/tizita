# 🇪🇹 ትዝታ-AI (Tizita-AI) — INSA Cyber Talent Summer Camp Assistant

**ትዝታ-AI (Tizita-AI)** is a lightweight, single-turn Q&A AI assistant designed to provide direct and immediate answers regarding the **National Ethio Cyber Talent Summer Camp** organized by Ethiopia's **Information Network Security Administration (INSA)**.

Built with a clean single-input UI (Input Question ➔ Get Immediate Answer), **ትዝታ-AI** strips away unnecessary chat history sessions for a fast, focused user experience.

---

## 📸 Core Features

* **Single-Turn Q&A Interface:** Instant question-and-answer format without session management overhead or scrolling chat threads.
* **Bilingual Support:** Smooth processing for queries submitted in Amharic or English.
* **Rich Knowledge Base:** Injected with complete operational details from INSA Cyber Talent Center (CTC).
